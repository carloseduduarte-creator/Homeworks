# Challenge 03 - Listas enlazadas

App hecha en React para practicar listas enlazadas y listas doblemente enlazadas.

Permite:

- Recorrer una lista de canciones en orden.
- Avanzar entre canciones.
- Navegar entre páginas de un historial.
- Avanzar y retroceder en el historial.

## Tecnologías

- React
- TypeScript
- Vite
